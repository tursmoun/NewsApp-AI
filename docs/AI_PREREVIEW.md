# Предпроверка публикаций

Ключ вводится только на компьютере сервера: запустите `setup-ai-key.cmd` (или ярлык «Настроить ключ Claude.cmd»). Ввод скрытый, хранение — Windows DPAPI в `.local/ai-secret.dpapi`, привязано к учётной записи Windows и этому компьютеру. После ввода перезапустите NewsApp. Прежний открытый ключ из `.local/ai-config.json` автоматически переносится в зашифрованное хранилище при запуске. Не переносите `.local` другим людям.

В CMS → Публикации → «Параметры предпроверки» видны статус подключения, название модели и переключатель. Поля ввода, просмотра и копирования ключа на сайте нет. API не возвращает ключ и отклоняет попытки записать его через сайт. Ключ передаётся серверу через окружение процесса. Администратор Windows или программа под вашей учётной записью по-прежнему может получить секрет — это не защита от полного доступа к компьютеру.

При включении отправляются заголовок, текст и ссылка на источник текущих ожидающих проверки версий, включая уже существующие заявки. Каждый запрос расходует баланс MWAPI. Фото, видео и данные аккаунта не отправляются. Заявки обрабатываются последовательно; ошибка повторяется до трёх раз с минутным интервалом. После исправления настроек нажмите «Повторить ошибочные проверки».

Две независимые оценки: соответствие новостному формату (подходит / нужен контекст / не соответствует) и признаки нарушений (нет явных / неоднозначные / высокий риск). Высокий риск → красная группа; неопределённость или неподходящий формат → жёлтая; подходящий текст без явных рисков → зелёная. Непроверенные вложения оставляют материал в жёлтой группе, если нет причин для красной.

Сортировка по умолчанию: высокий риск, ошибки, ещё не проверенные, нуждающиеся в проверке, без явных рисков. Есть фильтр группы; по умолчанию показаны ожидающие модерации заявки. Список обновляется раз в 10 секунд. После правок оценивается новая версия, старая оценка не переносится.

Оценка содержит причины, проверенные на наличие в тексте цитаты, модель и время. Недопустимый ответ провайдера означает ошибку, а не зелёную группу. Проверка не публикует, не отклоняет, не удаляет и не меняет порядок человеческих этапов модерации. Достоверность фактов и содержимое медиа проверяет человек.

Используется формат Claude Messages: POST https://api.mwapi.dev/v1/messages, Authorization: Bearer, anthropic-version: 2023-06-01. Реальная совместимость ключа, модели и маршрута MWAPI проверяется после ввода ключа. Качество классификации требует оценки на примерах вашей редакции; тесты с подставным ответом проверяют механизм, а не качество модели.

В рабочей локальной среде 22.10.2026 проверены запрос к `claude-sonnet-4-6` и обработка ожидающих заявок без изменения их статуса модерации. Это не гарантирует доступность той же модели для другого ключа.

Ошибки показываются по безопасному коду: авторизация, лимит запросов, настройки модели, тайм-аут, связь, некорректный или незавершённый ответ, несовпадающая цитата. Текст ответа провайдера и секреты в сообщения ошибок не записываются. После трёх попыток автоматические повторы останавливаются; администратор может вернуть ошибки в очередь через параметры предпроверки.
